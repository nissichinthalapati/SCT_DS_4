# SCT_DS_4 - Traffic Accident Analysis

## Overview

This project is completed as part of the SkillCraft Technology Data Science Internship - Task 04.

The objective is to analyze traffic accident data and identify patterns related to road conditions, weather, time of day, lighting conditions, casualty severity, and the number of vehicles involved.

## Dataset

The analysis uses the 2010 Road Traffic Accidents dataset.

- Records: 2,765
- Features: 15
- Data includes accident dates, times, road surface conditions, weather conditions, lighting conditions, location coordinates, casualty severity, and vehicle information.

## Analysis Performed

The project analyzes:

- Accidents by time of day
- Accidents by road surface condition
- Accidents by weather conditions
- Accidents by lighting conditions
- Accident hotspots based on location
- Accidents by casualty severity
- Accidents by number of vehicles involved

## Key Findings

- Afternoon recorded the highest number of accidents with 972 cases.
- Dry road surfaces accounted for the highest number of accidents, with 1,955 cases.
- Fine weather without high winds was the most common weather condition, with 2,363 cases.
- Most accidents occurred during daylight conditions with street lights present, with 1,979 cases.
- Slight casualties were the most common severity category, with 2,461 cases.
- Two-vehicle accidents were the most common, with 1,728 cases.
